# V5 prospective stage and tool study

Status: prepared after the exploratory v4 audit and before any v5 development or test model response. The v5 candidate, prompts, runner, verifier, and analysis will be frozen before a test call. V4 test results are closed to model or prompt selection within v5.

## Question

The v4 235B thinking condition did not beat random action choice, and its saved traces often ended while deriving intermediate quantities. V5 asks whether more thinking tokens improve the same model's one-step experimental choice, which numerical stage is inaccurate, and whether access to an exact public-input risk calculator enables a 32B agent to choose better interventions. The calculator condition measures a tool-using system, not unaided causal reasoning.

## Fresh data and count

Use the unchanged v4 episode generator and rejection rules with fresh seed 827419 in `configs/benchmark-action-v5.json`. Its `analysis_version` remains 4 because the *generator and model-free analysis contract* are reused; the model evaluation protocol is v5. Generate 9 development and 75 test episodes in each of two informative strata, with two or three observationally equivalent candidate orders. There are 18 development and 150 test episodes, all informative. The generator accepts 25 test episodes per optimal semantic action in each stratum. Joint parameters are disjoint within and across splits. No near-tie controls are included because the follow-up targets the informative action calculation.

The sample count is a precision choice, not a power guarantee. The v4 300-case model-minus-random 95% interval had half-width about 0.0029 nats. If variance is comparable, 150 independent cases should have a roughly 0.0041-nat half-width. That scale is smaller than the v4 random-to-oracle gap of 0.0272 nats, allowing a meaningful gap-closure effect to be detected. The v5 model-free audit, done before freezing or any v5 model response, found mean random-to-oracle gaps of 0.031296 and 0.023836 nats in its two 75-case test strata, or 0.027566 overall. The minimum gap in either stratum exceeds 0.0100. The 150 test joint-parameter IDs have zero overlap with v4. Their optimal presented labels are A/B/C = 57/51/42; optimal semantic actions are balanced 50/50/50.

## Conditions and metrics

Use pinned Qwen2.5-32B-Instruct-AWQ revision `5c7cb76a268fc6cfbb9c4777eb24ba6e27f9ee6c` for `q32_raw_stages` and `q32_calculator_agent`. Use pinned Qwen3-235B-A22B-Thinking-2507-FP8 revision `f07f63f2bbd7540917118ebdf3812696ef303b03` for `q235_short_raw_stages`, `q235_long_raw_stages`, and `q235_likelihood_stages`. The 235B short and long conditions have the same raw prompt and differ only in the maximum first-pass thinking tokens: 1,536 versus 3,584, followed by a constrained final stage JSON response. Sampling parameters and prompt-derived seeds match within that pair. Their paired action-risk difference is the **single confirmatory comparison**. Longer thinking is considered a meaningful improvement only if the 95% paired bootstrap interval's upper endpoint is below zero and the observed risk reduction is at least 0.005 nats. If the interval crosses zero, or the estimate is smaller than 0.005, the criterion fails. This practical threshold is about 18% of the v4 random-to-oracle gap. A 2,000-resample bootstrap over the 150 independent parameter draws uses seed 271828.

For each raw stage call, the model must report candidate-world query probabilities, the probability of one prespecified feasible outcome under action A in each world, posterior world probabilities after that outcome, expected one-step risk for A/B/C, and a final action ID. `q235_likelihood_stages` instead receives the exact query probabilities and all action-outcome likelihoods from public inputs; it reports posterior probabilities for the same probe, all three risks, and an action. Scores are per-stage mean absolute error, valid fraction, action risk relative to random and oracle, optimal-action fraction, and whether the selected action minimizes the model's *own reported* risks. This condition and all stage comparisons are descriptive mechanism diagnostics.

The 32B calculator agent receives the raw public task and may query an `evaluate_action` tool for up to three action IDs. Each tool result is the exact public-input one-step risk for the requested action. A final action is required even if it did not query every action. Log each request and returned risk. Compare its choice with `q32_raw_stages` on paired episodes, descriptively. The agent's tool use is not evidence of unaided numerical calculation.

The action score remains exact prior-averaged one-step Bayes risk in nats. Invalid final action receives the no-experiment initial risk. Numerical outputs outside their probability/risk domains count as invalid for the corresponding stage, not as a reason to exclude the episode. All test episodes are included. There is no test prompt tuning, episode exclusion, rerun, or substituted model after test calls begin. Development may check loading, schema, parsing, throughput, and affordability without changing the registered count, conditions, primary score, or decision rule.
