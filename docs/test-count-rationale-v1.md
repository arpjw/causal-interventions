# First locked evaluation count rationale

The first locked Qwen3-32B-AWQ evaluation uses 20 independent test parameter draws per each of the 18 declared factorial strata, for 360 test episodes total. A separate four-per-stratum development split is reserved for operational checks. The test split is generated and frozen before any model call on those episodes.

The choice balances the candidate counts (2, 3, 6), budgets (1, 2, 3), and informative versus near-tie regimes exactly. Every episode has an independent joint-parameter draw, so the analysis resamples parameters rather than repeated prompt calls. The primary comparison is paired model-minus-random mean excess log loss across all 360 episodes, with the interval defined in `causal_interventions/analysis.py`. Informative-stratum results and parse failures are reported separately. The near-tie strata remain in the registered overall mean, where the achievable action advantage is intentionally small.

The model-free 90-episode informative development check had random-minus-exact sample standard deviation about 0.04264 nats and expected opportunity gap about 0.00385 nats. Even 180 informative test episodes may not resolve a small fraction of that gap. This evaluation is powered to expose gross failures and provide a first bounded estimate across all strata; a confidence interval covering zero or a small advantage is inconclusive. We will not change the test count or prompt based on locked results. A better powered follow-up would require a new preregistered manifest and budget.

The 32B development throughput was 54 calls in 18 episodes, with roughly three seconds of model generation per episode after loading. At 360 test episodes, expected generation time is roughly 20 minutes, plus model initialization, manifest generation, CPU baselines, and provider overhead. A 90-minute per-run wall cap and the separately approved $10 total RunPod cap bound the attempt. If the run stops early, all completed records remain in the ledger and the partial run is not treated as the completed locked evaluation.
