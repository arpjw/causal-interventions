# Action-choice study v2: frozen design rationale

The first locked Qwen3-32B-AWQ run scored submitted probabilities as its primary outcome. A post-hoc replay of its action histories with exact Bayesian forecasts was close to random and oracle, but the action opportunity in that benchmark was small. The v2 primary estimand is the exact Bayesian posterior forecast loss after the model's chosen experiments, minus the same quantity after a seeded random policy. Submitted model forecasts remain secondary. This isolates experiment choice without granting the model any private information: the posterior uses only the public candidate worlds, prior, chosen actions, and observed outcomes.

Use 3 independent strata at budget one: two informative strata with 2 and 3 candidate worlds, and a 2-world near-tie control. The generator uses a coefficient bound of 1.2, minimum cell probability 0.0002, minimum query range 0.08, minimum one-step action gap 0.01, and minimum expected random-to-oracle opportunity gap 0.01 in each informative episode. The near-tie control has maximum action gap 0.0001. This is a new synthetic distribution, not a reanalysis of the prior locked test.

Generate 8 development and 50 fresh test episodes per stratum. The primary comparison pools the 100 informative test episodes, equal weighting per independent joint-parameter draw. The 50 near-tie episodes are secondary. The count is a capped prospective precision choice for a pilot, not a power guarantee. The local model-free CPU audit before any model test call found mean expected random-to-oracle gaps of 0.03188 and 0.02939 nats in the two informative test strata, with episode minima above 0.01. The near-tie mean was 0.0000287. Model-free audit is allowed at freeze; model responses on the fresh test are not used to adjust the design. A paired cluster bootstrap with 2,000 replicates supplies a descriptive 95% interval. Evidence of useful experiment selection requires the primary model-minus-random interval to lie entirely below zero. Gap closure is shown only if the realized random-to-oracle gap exceeds 0.01.

Prespecified model conditions: Qwen3-32B-AWQ revision 0499c3ac83fdef8810b907a23894ba91e95eddd8 with a 384-token thinking stage, temperature 0.6, top-p 0.95, top-k 20, and a JSON-constrained final continuation; and Qwen2.5-72B-Instruct-AWQ revision 698703eae6604af048a3d2f509995dc302088217 with thinking disabled, temperature 0.7, top-p 0.8, top-k 20, and JSON object constrained decoding. Both use the same primary-v2 prompt and seed derived from each prompt hash. They are different architecture and instruction families, so the comparison is a capability contrast rather than an isolated parameter-scaling effect. No retries are made after malformed action or forecast output. For thinking mode, the adapter allows at most 384 reasoning tokens. If the model has not closed its thinking block, the adapter appends `</think>` and asks for a JSON-constrained continuation. If it closes the block and already provides complete JSON, that answer is used. Both stage outputs and their token counts are retained in the private ledger. This is a budgeted-thinking condition. Action tokens are capped at 1536 and forecast tokens at 1536 for 32B thinking; at 96 and 128 for 72B direct. Each episode makes at most two model calls. A failed or truncated response remains a failure.
